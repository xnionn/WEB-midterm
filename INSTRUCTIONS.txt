1. Открой терминал в корне своего клона репозитория WEB-midterm.

2. Настрой свои имя и почту для Git (чтобы коммит был засчитан именно тебе):
   git config user.name "Azamat Bukharbaev"
   git config user.email "azamat.bukharbaev@example.com"

3. (Опционально) Создай свою ветку:
   git checkout -b azamat/gatherings-and-booking

4. Скопируй файлы из этого zip-архива в корень репозитория (с заменой, если нужно).

5. Добавь в коммит свои закрепленные файлы:
   git add content/gatherings.html
   git add gatherings.html
   git add assets/js/data/gatherings.js
   git add assets/js/pages/gatherings.js
   git add assets/css/pages/gatherings.css

6. Сделай коммит:
   git commit -m "feat(gatherings): implement DOM cards, category filters, stats and booking modal"

7. Отправь в репозиторий:
   git push origin azamat/gatherings-and-booking
   (или git push origin main, если коммитите напрямую в main)
